💡 **What:** Replaced the sequential `for` loop in `CleanupRegistry.runOnce()` with a concurrent `await Promise.all()` execution.

🎯 **Why:** The previous implementation awaited each async cleanup function sequentially. This means that if multiple cleanup tasks involved I/O, waiting for timers, or other non-blocking async operations, their delays compounded. By using `Promise.all()`, we can map the cleanup callbacks to promises and execute them all concurrently, which is significantly faster.

📊 **Measured Improvement:** We established a benchmark with `vitest bench` to measure the performance of `runOnce` with 1,000 async cleanups (each simulating a 1ms delay).

*   **Baseline:** The original sequential code ran at roughly **0.83 ops/sec** (approx. 1200ms mean time per run).
*   **Improvement:** The optimized code ran at roughly **457 ops/sec** (approx. 2.18ms mean time per run).

This results in a massive >500x speedup for the scenario with many asynchronous cleanup tasks.
