# ADR 0001: Architecture Overview

## Status
Accepted

## Context
This document records the key architectural decisions for this service.

## Decision
- Language/framework: Node.js 20 + Python 3.11
- Database: PostgreSQL + SQLite
- Message queue: Redis + gRPC
- Deployment: Docker + Kubernetes

## Consequences
- Team expertise alignment
- Operational tooling compatibility
- Performance characteristics
